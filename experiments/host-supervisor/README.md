# Development host reference snapshot

This host coordinates external agent decisions, bounded lifecycle, evidence and exact rollback. It supports explicit `stepwise_input` while keeping the refresh default. It does not include an LLM or an automatic Search sequence. The Inspector is an evidence index, not a second action authority.

The source is a development reference, with account-name placeholders. The private installation manifests, transfer plans, APK, raw logs and execution configs are deliberately absent. Configure trusted local paths and independently bind reviewed versions before attempting deployment; this directory is not a portable installer. Do not run it against an existing machine by copying development defaults.

The generic agent-input success path does not require a person typing, signing a declaration or running a test editor. Normal Stop, exact rollback, full XML/hash, precise node/focus and unknown-input non-replay remain required. See the milestone validation scope in ../../docs/milestone-20261022.md.
